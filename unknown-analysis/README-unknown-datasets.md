# 未知（未解真名）参数数据集说明

数据来源：`outputs/knob-library/`（195 份解密参数配置，8 个机型）。
这些键的 `name` 为 null（真名未还原），**但数值完整、真实**，可直接用于分析与转换。

## 一、总览

| 指标 | 数值 |
|---|---|
| 配置文件 | 195 份 |
| 参数总条目 | 165,154 |
| 已解真名 | 26,097 |
| **未解真名（未知）** | **139,057** |
| 未知键去重后 | 1,572 个 |
| 其中跨配置恒定 | 973 个（机器常量/开关） |
| 其中随配置变化 | 599 个（材料/层厚相关） |

## 二、文件清单

| 文件 | 用途 |
|---|---|
| `unknown_keys_summary.csv` | 每个未知键一行：出现次数/机型数/材料数/层厚数/取值种类/是否恒定/全部取值 |
| `unknown_keys_physics_profile.csv` | 每个未知键的数量级画像：数值 min/max、相对跨度%、取值样例 |
| `unknown_values_long.csv` | 长表：每份配置 × 每个未知键的数值（139,057 行，最适合透视/筛选）|
| `unknown_varying_wide.csv` | 宽表：599 个变化键 × 195 份配置（一眼看跨材料差异）|
| `unknown_constant_keys.csv` | 973 个恒定键及其恒定值（可直接沿用，无需关心名字）|
| `unknown_F4_vs_ST1_compare.csv` | **Form 4 vs Studio 1** 共有的 745 个未知键逐键对比 |
| `unknown_<机型>.csv` | 每个机型内部的未知键（只列变化键）宽表 |
| `unknown_by_category.csv` | 按 category_key 汇总：未知键数/变化/恒定/条目数/涉及机型 |
| `unknown_key_materials_matrix.csv` | 关键材料对照矩阵（Flex80A/ClearCast/Tough1500/Grey/Clear/White 的 F4↔ST1 同名材料）|

## 三、Form 4 vs Studio 1 共有未知键（745 个）

| 类别 | 数量 | 含义 |
|---|---|---|
| 双机恒定 | 450 | 两机型都是固定值，可直接照搬 |
| 仅 F4 随材料变 | 98 | F4 上因材料而变、ST1 上固定 → 换机时可能需固定为 ST1 值 |
| 仅 ST1 随材料变 | 26 | ST1 特有随材料变化 |
| 双机都随材料变 | 171 | 真正的材料相关参数，最需要人工核对映射 |
